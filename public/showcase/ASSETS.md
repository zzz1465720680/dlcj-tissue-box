# 展示页图片来源

- `hero-studio-*`：内置 imagegen 生成的浅灰背景白绿纸巾盒主视觉。
- `customize-collection-*`：内置 imagegen 生成的绿、蓝、橙撞色组合。绿色产品无标识；蓝橙款沿用参考图中的灰色英文标识。
- `craft-detail-*`：用户提供的 `纸巾盒0914_品牌广告/01_图文成品/03_细节特写.png`，网页用 CSS 裁切展示产品细节。
- `car-scene-*`：用户提供的 `纸巾盒0914_品牌广告/工作文件/视频画面/V2_车内场景.png`，页面标为场景示意。

所有网页图片均为 WebP 压缩副本。实际生成的两张新海报原图尺寸均为 1672 × 941。保留原始产品的软质轮廓、开口、打孔包角与撞色包边。文字和按钮由网页单独排版。
